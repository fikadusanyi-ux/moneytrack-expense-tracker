MoneyTrack Expense Tracker (HTML, CSS, JavaScript)\n\nFiles:\n- index.html: page structure\n- style.css: design and responsive layout\n- script.js: transactions, filters, totals, localStorage and CSV export\n\nTo run: open index.html in your browser.\nTo publish on GitHub Pages: upload index.html, style.css and script.js to the root of your repository, then go to Settings > Pages and select Deploy from a branch, main, /(root).\nNote: data is stored in this browser using localStorage. Currency display is USD by default.\n
